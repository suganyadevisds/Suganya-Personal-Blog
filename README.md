# Suganya Devi – Personal Blog & Developer Portfolio

## Project Overview

A responsive personal blog and web developer portfolio created to showcase my professional journey, web development experience, projects, technical skills, and achievements.

The website presents my experience through blog-style cards, topic navigation, personal information, and contact details.

## Key Features

- Personal introduction and developer profile
- Blog-style project showcase
- Career journey and professional milestones
- Project categories and topic navigation
- About Me section
- Contact information and email link
- Popup content for detailed blog posts
- Responsive navigation for desktop and mobile
- Light-theme interface
